Section 01

The Three Protocols

The Protocol Stack of the Agent Web

A2A
Agent-to-Agent Protocol. Agents talk to each other.
Skills (SKILL.md)
Portable capabilities. Write once, use in any agent.
MCP
Model Context Protocol. Agents connect to tools.
Infrastructure
Servers, APIs, databases, file systems.

MCP is USB-C for AI. One standard interface, any tool. An MCP server can work with Claude, Cursor, VS Code Copilot, Windsurf, and any MCP-compatible client. Created by Anthropic, November 2024.

Agent Skills package domain expertise into reusable capabilities. A skill is a folder with a SKILL.md file. Works across Claude Code, OpenAI Codex, GitHub Copilot, and any tool supporting the standard. Released December 2025.

A2A (Agent-to-Agent) lets agents from different vendors collaborate without sharing memory or tools. Built on HTTP + SSE + JSON-RPC. Created by Google, now under the Linux Foundation. 50+ launch partners including Salesforce, SAP, PayPal, and LangChain.

Section 05

Build Something

Two Apps You Can Build Today

The best way to understand protocols
is to ship something that uses them.

App 1: Bookmark Brain (Python, 30 min)

An MCP server that lets AI agents search and manage your bookmarks. 3 tools, 1 resource. Works with Claude, Cursor, any MCP client.

# Install pip install fastmcp # server.py from fastmcp import FastMCP mcp = FastMCP("Bookmark Brain") @mcp.tool() def add_bookmark(url: str, title: str, tags: list[str]) -> str: """Save a bookmark with tags.""" # Save to JSON, return confirmation @mcp.tool() def search_bookmarks(query: str) -> list[dict]: """Search by title, URL, or tag.""" # Test: fastmcp dev server.py # Install: claude mcp add bookmark-brain -- python3 server.py

App 2: Project Tracker (TypeScript, 45 min)

An MCP server that tracks your side projects. Add projects, update status, get a dashboard. 3 tools, 1 prompt.

// Install npm install @modelcontextprotocol/sdk zod // server.ts import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js"; const server = new McpServer({ name: "Project Tracker", version: "1.0.0" }); server.tool("add_project", "Add a new project", { name: z.string(), stack: z.string(), status: z.enum(["idea", "building", "live"]) }, async ({ name, stack, status }) => { // Save to JSON, return confirmation } ); server.tool("dashboard", "Get project dashboard", {}, async () => { // Return grouped by status } ); // Test: npx @modelcontextprotocol/inspector node server.js
